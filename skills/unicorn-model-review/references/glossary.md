# 图表标注时容易混用的术语

|术语|本书口径|影响哪个判断|
|---|---|---|
|BSL / SSL（2.1）|作者将前高上方和前低下方分别视为买侧及卖侧流动性的候选位置|图上能查证是否越过极值，实际挂单量未知|
|ERL / IRL（2.3）|给定区间以外的高低点，与区间内的小极值或失衡|先锁定区间，再区分近端和远端目标|
|Equilibrium（3.1）|选定高低点的价格中点，上半为溢价，下半为折价|区间变化时这个中点也变|
|POI（3.3）|预先标记、供观察价格反应的区域|记录其所属周期与有效时间|
|Sweep（4.2）、MSS（4.4）|先越过已有极值，随后反向突破局部结构|只有越界仍缺结构转换|
|Displacement（4.4、8.1）|实体明显、方向明确地收过关键位|拖行或仅有影线刺穿时无法确认|
|Breaker / Mitigation Block（4.3）|先扫单再强势击穿原订单块形成 Breaker；未扫先破属于作者区分的另一类|决定是否继续审查 Unicorn|
|FVG（5.2）|三根连续 K 线中，第一与第三根影线范围之间的空档，中间一根承担位移|向上用第一高与第三低，向下用第三高与第一低|
|CE / Mean Threshold（5.4、4.5）|分别是 FVG 与 Breaker 的中点|均须标出计算对象，与整个参考区间的均衡位有别|
|Unicorn（6.3–6.4）|扫单后的结构位移产生 Breaker，同次位移留下的 FVG 与它重叠|用两区间的共同价格带核对回踩|
|Killzone（6.2）|作者观察日内扩张的时段|波段模型优先看结构位置|
|BE（9.1）|第一目标兑现后将余仓的保护价移至入场价|成交成本会影响净盈亏|
|IPDA（1.2）|作者用来解释价格向流动性与失衡区移动的假说|可用于理解书中叙事；K 线无法识别机构身份或集中控制机制|
