# The Unicorn Model · 整书地图

Takumi Tominaga，2026。EPUB 题名页与包元数据相符。作者希望读者在回撤前就能回答三个问题：扫过哪个极值、哪次位移改变了结构、回到哪里才符合这套模型？

|任务|原书位置|复盘交付物与作用|
|---|---|---|
|T1 定背景|第1–3章、6.2、8.4|高周期区间、上下半区、流动性目标与时段；判断局部信号的环境|
|T2 定形态|第4–5章、6.3–6.4、8.1–8.3|按时间排列扫单、位移和结构转换，标出 Breaker 与三根 K 线生成的 FVG，计算交集；筛除相邻假信号|
|T3 定执行|6.5、第7章、9.1|区别首次触及与收盘确认，写出两类止损、目标与未成交分支；供回放对照|
|T4 定风险|9.2|用止损距离和每点价值折算仓位，再检查总敞口、相关性与日损上限|
|T5 定复盘|第7–8、10–11章|对照入场前、执行时、平仓后三个截面，区分执行失误与按计划亏损|

三组实例是 EUR/USD 空头、黄金与 Nasdaq 多头。它们展示规则怎样落到图表上；书名中的高概率缺乏可复算的完整样本。IPDA、机构意图与“价格债务”属于作者的解释框架。图表能支持的是极值、K 线顺序、价格区间和后续反应。强位移没有统一数值阈值，回测时应记录判读口径。
