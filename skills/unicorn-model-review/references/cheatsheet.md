# 决策规则速查 — The Unicorn Model

| 能力 | 一句话规则 |
|---|---|
| 标注区间和高周期背景 | 判断候选处于哪个参考区间，是否有逆向障碍 |
| 验证独角兽形态 | 按事件顺序验证扫单与位移，并计算 Breaker 和 FVG 的重叠区 |
| 回放入场和分批退出 | 从确认后的回踩逐步判读成交、失效、分批止盈和余仓 |
| 折算仓位并核对风险额度 | 按用户给定的账户与合约参数计算模拟仓位及组合约束 |
| 审阅日志与退出规则 | 用同一品种的逐笔记录评估保本时机、执行偏差和样本缺口 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
